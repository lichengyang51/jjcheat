# JJCheat —— iPhone 录屏 + 画中画版

给 **iPhone 16 Pro Max / iOS 26.7** 这种没有越狱的机器用。

---

## 它到底怎么工作

```
① 你从控制中心开录屏（选 JJCheat 广播）
        ↓
② Broadcast Extension 拿到整屏画面，缩成 1/3，本地回环发给主 App
        ↓
③ 主 App 识别棋盘 → 认出对方走了哪一步 → 引擎推演
        ↓
④ 画中画浮窗实时画出：棋盘 + 红色箭头 + 走法 + 分数 + 胜率
```

浮窗飘在 JJ象棋 上方，可以拖动、可以双指放大。**放大到和棋盘一样大、拖到棋盘位置，就等于给棋盘加了标注。**

---

## 为什么是画中画，而不是盖在棋盘上

iOS 系统封死了「第三方 App 在别人 App 上绘制」这条权限，未越狱的机器拿不到。

画中画（PiP）是系统**明确开放**的、能浮在任意 App 之上的唯一通道。所以箭头只能落在自己的浮窗里。

## 第一步：云端编译出 ipa

你手上是 Windows，Xcode 只能在 macOS 上跑。用 GitHub Actions 的 macOS 机器白嫖编译。

1. 注册/登录 GitHub，新建一个 **Private** 仓库（名字随意，比如 `jjcheat`）。
2. 把 `jjchess` 整个文件夹上传进去。网页端可以直接拖拽上传，命令行更快：

   ```bash
   cd C:\Users\Administrator\Desktop\富江富江\jjchess
   git init
   git add .
   git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/jjcheat.git
   git push -u origin main
   ```

3. 打开仓库 → 顶部 **Actions** 标签 → 左侧点 **build-ios-app** → 右侧 **Run workflow** → 绿色按钮。
4. 等 6–10 分钟（第一次装 XcodeGen 会慢一点）。
5. 进这次运行记录 → 页面最下面 **Artifacts** → 下载 **JJCheat-ipa**，解压得到 `JJCheat-unsigned.ipa`。

> 编译失败的话，把失败那一步的日志贴出来，看是哪一行 Swift 报错。

## 第二步：签名装进手机

ipa 是未签名的，iPhone 不会认。用 **Sideloadly**（Windows 版，免费）：

1. 电脑装 [iTunes](https://www.apple.com/itunes/)（微软商店版不行，要苹果官网的 exe 版，Sideloadly 依赖它的驱动）。
2. 下载 [Sideloadly](https://sideloadly.io/)，安装。
3. iPhone 用数据线连电脑，手机上点「信任」。
4. 打开 Sideloadly：
   - **IPA**：选 `JJCheat-unsigned.ipa`
   - **Apple ID**：填你的 Apple ID（免费账号即可）
   - 点 **Start**，输入 Apple ID 密码
5. 装完后手机上：`设置 → 通用 → VPN与设备管理 → 开发者APP` → 信任你的 Apple ID。
6. **还差最后一步**：`设置 → 隐私与安全性 → 开发者模式` → 打开 → 重启手机 → 确认。

### 关于有效期

| 账号类型 | 有效期 | 到期后 |
|---|---|---|
| 免费 Apple ID | **7 天** | 重新用 Sideloadly 签一次（1 分钟） |
| 付费开发者（￥688/年） | 1 年 | 一年一签 |

免费账号想省事的话装个 **AltStore**，同一 WiFi 下每 7 天自动续签。

## 第三步：手机上跑起来

### ① 开始录屏

1. 打开 **JJCheat** App。
2. 点「**开始录屏**」→ 弹出系统面板 → 选「**JJCheat 录屏**」→ 点「**开始直播**」。
3. 顶部出现红色录制指示（正常现象，录屏就长这样）。

### ② 校准棋盘

1. 切到 **JJ象棋**，进到有棋盘的界面（练习场最快）。
2. 切回 **JJCheat**（录屏还在继续跑）。
3. 点「**点我校准**」，会弹出刚才录到的画面。
4. 在画面上依次点棋盘最外圈 4 个交叉点：**左上 → 右上 → 右下 → 左下**。
5. 点「完成」。坐标自动存盘，以后不用再点。

### ③ 学习棋盘

回到 JJ象棋，**开一局新棋**（让画面停在标准开局），再切回 JJCheat。
程序会自动抓 58 个空位学背景色、32 个棋子学模板。顶部会提示「棋盘学习完成」。

> 学一次就够了。以后残局、中局都能直接跑。

### ④ 打开浮窗，开始下棋

1. 点「**③ 打开画中画**」。
2. 屏幕角落浮出小窗。
3. 切回 **JJ象棋**，开打。
4. 浮窗里会实时显示箭头和文字。**双指放大 + 拖动，盖到棋盘上**。

## 自检（不用手机也能验）

在 `jjchess` 目录下：

```bash
node tools/perft.js 4      # 走法生成：d1..d4 全 OK 才算对
node tools/bench.js 1500   # 引擎：nps / 深度 / 合法性
node tools/bundle.js       # 重新生成 dist/engine.js
node tools/test-bundle.js  # 模拟 JSC 沙箱 + 合成图像识别
```

改引擎只动 `src/cst/eval.js`，重跑 `node tools/bundle.js`，把新的 `dist/engine.js`
覆盖 `ios/app/JJCheatApp/Resources/engine.js`，重新编译即可。

## 排障

| 现象 | 原因 | 处理 |
|---|---|---|
| 一直「等待录屏」 | Extension 没连上主 App | 确认 JJCheat 先打开过、没被系统杀掉；重新开录屏 |
| 浮窗弹不出来 | PiP 被系统拦 | 看 Xcode 控制台 `[JJCheat] PiP` 开头的日志 |
| 画面卡住 | 帧堆积 | 已经做了丢帧保护，卡住就重开录屏 |
| 识别偏差大 | 四角点歪了 | 重新校准 |
| 一直「学习中」 | 画面不是开局 | 退出重开一局 |
| 7 天后闪退 | 免费签名到期 | Sideloadly 重签 |

日志过滤关键词：`[JJCheat]`。
